# Home Assistant App: Pantry Hub

RFID pantry inventory: Chainway UR4 reads become Grocy stock, with a
barcode + RFID linking station.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

- Tagged items that arrive in the pantry are added to Grocy; items that
  leave are consumed (the exact unit).
- Link tags to Grocy products with the barcode + RFID linking station.
- Entities for reader status, tag counts, the Grocy queue and item events.

See the **Documentation** tab.
